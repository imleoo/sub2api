三步完成企业内部部署Three Steps to Go Live

支持 Docker / Kubernetes 一键部署，也可直接编译二进制运行，无外部依赖，接管企业 AI 接入全流程。 Docker / Kubernetes one-click deployment or compile-to-binary with no external dependencies — take over the full enterprise AI access workflow.

1

私有化安装Private Installation

通过 Docker Compose 或 Kubernetes Helm Chart 在企业内网一键部署，自动初始化 PostgreSQL 与 Redis，5 分钟内完成启动。Deploy to your intranet via Docker Compose or Kubernetes Helm Chart. Auto-initializes PostgreSQL and Redis — live in under 5 minutes.

# Docker Compose 一键启动
docker compose up -d
# 访问安装向导
open http://localhost:3000/setup
2

配置供应商 APIConfigure Providers

在管理后台录入各供应商 API Key（Anthropic / OpenAI / Google 等），系统自动进行负载均衡和故障切换，实现多渠道高可用接入。Enter provider API keys (Anthropic / OpenAI / Google, etc.) in the admin console. The system auto-handles load balancing and failover across channels.

# 支持的供应商（示例）
providers:
  - anthropic: sk-ant-...
  - openai:   sk-...
  - google:   AIza...
3

分发内部 API KeyIssue Internal Keys

为各部门或项目组创建子 API Key，配置模型白名单与配额上限，分发后即可直接调用，兼容 OpenAI SDK，无需改动业务代码。Create sub-keys per department or project team. Configure model whitelists and quota caps — fully OpenAI SDK compatible, no business code changes required.

from openai import OpenAI
client = OpenAI(
  base_url="https://api.cxm.icu/v1",
  api_key="sk-内部分发 Key"
