### 2. 用户端模型广场 (Models)

用户可查看账号白名单内的可用模型、定价、折扣、图片模型等信息。

**前端**

| 文件 | 说明 |
|-----|------|
| `frontend/src/views/user/ModelsView.vue` | 模型广场页面（白名单过滤、图片模型、版本过滤、复制模型名） |
| `frontend/src/views/user/__tests__/ModelsView.spec.ts` | 对应测试 |
| `frontend/src/api/models.ts` | API 客户端，含 `ModelInfo.discount_rate`、`ModelsResponse.cny_rate` |
| `frontend/src/router/index.ts` | `/models` 路由（`SupportedModels`） |
| `frontend/src/i18n/locales/zh.ts` & `en.ts` | `models.*`、`nav.models` 键值 |

**后端**

| 文件 | 说明 |
|-----|------|
| `backend/internal/server/routes/user.go` | `GET /api/v1/models` |
| `backend/internal/handler/usage_handler.go` | `ListModels` 方法，白名单过滤 + 图片模型归一化 |

**关键功能特性**
- 账号白名单过滤：只显示 `credentials.model_mapping` 配置的模型，不展示全量定价表
- 图片模型：`gpt-image-*`、`dall-e*`、`imagen-*`、`gemini-*-image` 等须在白名单内可见
- 复制模型名：带剪贴板 fallback 和短暂"已复制"状态
- 价格显示：折后价 + 折扣标签 + 人民币价格（由后端 `cny_rate` 驱动）

**合并注意**：路由 `/models`、`ModelsView.vue`、`ListModels`、i18n 键必须保留；不要退回"展示全量定价表"行为。
