## 2. 用户端模型列表 (Models)

为用户提供可见模型列表查看功能，包括模型定价、可用性、特性等信息。

### 前端文件

| 文件路径 | 说明 |
|---------|------|
| `frontend/src/views/user/ModelsView.vue` | 模型列表页面组件（含版本过滤逻辑） |
| `frontend/src/api/models.ts` | 模型 API 客户端 |
| `frontend/src/router/index.ts` | 路由配置（`/models` 路径） |
| `frontend/src/components/layout/AppSidebar.vue` | 侧边栏 ModelGridIcon 图标及菜单项 |
| `frontend/src/i18n/locales/zh.ts` | 中文国际化（`models` 及 `nav.models`） |
| `frontend/src/i18n/locales/en.ts` | 英文国际化（`models` 及 `nav.models`） |

### 后端文件

| 文件路径 | 说明 |
|---------|------|
| `backend/internal/server/routes/user.go` | 用户路由（`GET /api/v1/models`） |
| `backend/internal/handler/usage_handler.go` | `ListModels` 方法 |

### 功能特性
- 模型版本过滤：Claude 4.5+、GPT 5.2+、Gemini 3+、GLM 5+
- 支持 Provider/Mode 筛选
- 显示定价信息、上下文窗口、特性标签（Vision、Prompt Caching 等）

### 合并注意事项
- 路由配置需保留 `/models` 路径
- AppSidebar 中保留 `ModelGridIcon` 和菜单项
- 国际化文件保留 `models` 相关键

## 3. 用户数据统计 (Admin User Handler)

后端管理中用户数据统计相关功能，包括用户并发度查询。

### 后端文件

| 文件路径 | 说明 |
|---------|------|
| `backend/internal/handler/admin/user_handler.go` | 用户管理 Handler（含 `UserWithConcurrency` 结构） |
| `backend/internal/server/routes/admin.go` | 用户管理路由（`/api/v1/admin/users/*`） |
| `backend/cmd/server/wire_gen.go` | DI 配置（`adminUserHandler` 实例化） |

### 关键代码位置

**wire_gen.go** (约 280 行):
```go
adminUserHandler := admin.NewUserHandler(adminService, concurrencyService)
```

**routes/admin.go** (registerUserManagementRoutes):
```go
users.GET("", h.Admin.User.List)  // 包含并发度信息
users.GET("/:id", h.Admin.User.GetByID)
users.GET("/:id/usage", h.Admin.User.GetUserUsage)
```

### 合并注意事项
- wire_gen.go 中需保留 `adminUserHandler` 实例化代码
- user_handler.go 中 `UserWithConcurrency` 结构和并发度查询逻辑需保留

## 4. 词云功能 (Prompt Analytics)

从用户提示词中提取关键词统计，以词云和表格形式展示。

### 后端文件

| 文件路径 | 说明 |
|---------|------|
| `backend/internal/plugin/promptanalytics/handler.go` | HTTP Handler（`GetTopKeywords`） |
| `backend/internal/plugin/promptanalytics/repository.go` | 数据仓储层（Redis 存储） |
| `backend/internal/plugin/promptanalytics/middleware.go` | Gin 中间件（请求拦截） |
| `backend/internal/plugin/promptanalytics/keyword_extractor.go` | 关键词提取算法 |
| `backend/internal/plugin/promptanalytics/config.go` | 配置定义 |
| `backend/internal/server/routes/admin.go` | 路由注册（`registerPromptAnalyticsRoutes`） |
| `backend/internal/server/routes/gateway.go` | 网关路由中使用 `promptAnalytics` 中间件 |
| `backend/cmd/server/wire_gen.go` | DI 配置（`promptAnalyticsPlugin`、`promptAnalyticsHandler`） |

### 前端文件

| 文件路径 | 说明 |
|---------|------|
| `frontend/src/views/admin/PromptAnalyticsView.vue` | 词云管理页面 |
| `frontend/src/api/admin/promptAnalytics.ts` | 词云 API 客户端 |
| `frontend/src/i18n/locales/zh.ts` | 中文国际化（`admin.promptAnalytics`） |
| `frontend/src/i18n/locales/en.ts` | 英文国际化（`admin.promptAnalytics`） |

### API 端点

```
GET /api/v1/admin/prompt-analytics/top-keywords
```

参数：
- `period`: 年月格式（如 `2024-01`）
- `user_id`: 用户ID（可选，留空查全局）
- `limit`: 返回数量（默认 50，最大 200）

### 关键代码位置

**wire_gen.go** (约 260-270 行):
```go
promptAnalyticsPlugin := promptanalytics.NewPlugin(cfg.PromptAnalytics)
promptAnalyticsHandler := promptanalytics.NewHandler(promptAnalyticsRepo)
```

**routes/admin.go**:
```go
registerPromptAnalyticsRoutes(admin, promptAnalyticsHandler)
```

**routes/gateway.go** (中间件使用):
```go
r.POST("/responses", ..., promptAnalytics, ...)
r.POST("/chat/completions", ..., promptAnalytics, ...)
```

### 合并注意事项
- 整个 `backend/internal/plugin/promptanalytics/` 目录需保留
- wire_gen.go 中保留 `promptAnalyticsPlugin` 和 `promptAnalyticsHandler` 初始化
- gateway.go 中保留 `promptAnalytics` 中间件调用
- 前端 PromptAnalyticsView.vue 和 API 文件需保留
