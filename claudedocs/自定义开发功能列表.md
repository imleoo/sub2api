### 2. 用户端模型广场 (Models)

用户可查看账号白名单内的可用模型、定价、折扣、图片模型等信息。

**前端**

| 文件 | 说明 |
|-----|------|
| `frontend/src/views/user/ModelsView.vue` | 模型广场页面（白名单过滤、图片模型、版本过滤、复制模型名） |
| `frontend/src/views/user/__tests__/ModelsView.spec.ts` | 对应测试 |
| `frontend/src/api/models.ts` | API 客户端，含 `ModelInfo.discount_rate`、`ModelsResponse.cny_rate` |
| `frontend/src/router/index.ts` | `/models` 路由（`SupportedModels`） |
| `frontend/src/i18n/locales/zh.ts` & `en.ts` | `models.*`、`nav.models` 键值 |

**后端**

| 文件 | 说明 |
|-----|------|
| `backend/internal/server/routes/user.go` | `GET /api/v1/models` |
| `backend/internal/handler/usage_handler.go` | `ListModels` 方法，白名单过滤 + 图片模型归一化 |

**关键功能特性**
- 账号白名单过滤：只显示 `credentials.model_mapping` 配置的模型，不展示全量定价表
- 图片模型：`gpt-image-*`、`dall-e*`、`imagen-*`、`gemini-*-image` 等须在白名单内可见
- 复制模型名：带剪贴板 fallback 和短暂"已复制"状态
- 价格显示：折后价 + 折扣标签 + 人民币价格（由后端 `cny_rate` 驱动）

**合并注意**：路由 `/models`、`ModelsView.vue`、`ListModels`、i18n 键必须保留；不要退回"展示全量定价表"行为。

### 3. 管理员用户使用统计

管理员可查看单个用户的详细使用数据（汇总、每日历史、模型分布、端点分布）。

**前端**

| 文件 | 说明 |
|-----|------|
| `frontend/src/views/admin/UsersView.vue` | 用户列表，含"查看统计"入口 |
| `frontend/src/components/admin/user/UserStatsModal.vue` | 统计弹窗 |
| `frontend/src/api/admin/users.ts` | `GET /api/v1/admin/users/:id/usage` |

**后端**

| 文件 | 说明 |
|-----|------|
| `backend/internal/handler/admin/user_handler.go` | `GetUserUsage`，依赖真实 usageLogRepo（非 mock） |
| `backend/internal/service/admin_service.go` | `GetUserUsageStats` 签名变更为 `(startTime, endTime time.Time)`，调用 `usageLogRepo` |
| `backend/internal/repository/usage_log_repo.go` | 新增 `GetUserUsageStats`，复用 `getEntityUsageStats` 私有方法 |

**API**：`GET /api/v1/admin/users/:id/usage`，返回 `summary`、`history`、`models`、`endpoints`。

**合并注意**：`AdminService.GetUserUsageStats` 签名已变更，`wire_gen.go` 中 `NewAdminService` 参数需包含 `usageLogRepo`；不能退回返回 mock 数据的旧实现。

### 4. 词云分析 (Prompt Analytics)

从网关请求体中实时提取关键词，生成月度词云和 Top-N 排行。

**后端**

| 文件 | 说明 |
|-----|------|
| `backend/internal/plugin/promptanalytics/` | 全目录：handler、repository、middleware、keyword_extractor、config、wire |
| `backend/internal/server/routes/admin.go` | `registerPromptAnalyticsRoutes` |
| `backend/internal/server/routes/gateway.go` | `promptAnalytics` 中间件挂载 |
| `backend/cmd/server/wire.go` & `wire_gen.go` | `promptAnalyticsPlugin`、`promptAnalyticsHandler` 初始化 |
| `backend/ent/schema/keyword_stat.go` | Ent Schema |
| `backend/migrations/082_create_keyword_stats.sql` | 数据库迁移 |

**前端**

| 文件 | 说明 |
|-----|------|
| `frontend/src/views/admin/PromptAnalyticsView.vue` | 词云管理页 |
| `frontend/src/api/admin/promptAnalytics.ts` | API 客户端 |
| `frontend/src/router/index.ts` | `/admin/prompt-analytics` 路由 |
| `frontend/src/i18n/locales/zh.ts` & `en.ts` | `admin.promptAnalytics.*` 键值 |

**API**：`GET /api/v1/admin/prompt-analytics/top-keywords?period=YYYY-MM&user_id=&limit=50`

**合并注意**：`gateway.go` 中的 `promptAnalytics` 中间件必须保留，否则词云无数据；`wire_gen.go` 中两个初始化变量必须保留。

### 5. 模型折扣与人民币定价

管理员可对模型设置折扣率，计费时自动应用；用户端同步展示折后价和人民币换算价。

**配置 / 数据**

| 文件 | 说明 |
|-----|------|
| `backend/data/model_discounts.json` | 折扣配置文件（可被 DB 热覆盖） |
| `backend/data/model_pricing.json` | 运行时定价数据（SHA256 校验） |

**后端**

| 文件 | 说明 |
|-----|------|
| `backend/internal/config/config.go` | `PricingConfig.CNYRate`（默认 7）、`PricingConfig.DiscountFile` |
| `backend/internal/service/pricing_service.go` | `loadDiscounts`、`SaveDiscounts`、`GetDiscount`、`GetCNYRate`、`GetCurrencyMode`、`ListAllModels`、`ModelInfo` 结构体 |
| `backend/internal/service/billing_service.go` | `applyDiscount()` 方法，`GetModelPricing` 调用链中插入 |
| `backend/internal/service/domain_constants.go` | `SettingKeyCNYRate`、`SettingKeyCurrencyMode` 常量 |
| `backend/internal/handler/admin/setting_handler.go` | `GetModelDiscounts`/`UpdateModelDiscounts` API；`SettingHandler` 新增 `pricingService`、`adminService` 字段 |
| `backend/internal/handler/dto/settings.go` | `CurrencyMode`、`CNYRate` 字段 |
| `backend/internal/service/setting_service.go` | `CurrencyMode`、`CNYRate` 字段持久化 |
| `backend/internal/service/settings_view.go` | Settings 视图新增货币字段 |
| `backend/internal/server/routes/admin.go` | `GET/PUT /api/v1/admin/settings/model-discounts` |

**前端**

| 文件 | 说明 |
|-----|------|
| `frontend/src/views/admin/ModelDiscountsView.vue` | 折扣管理页 |
| `frontend/src/router/index.ts` | `/admin/model-discounts` 路由 |
| `frontend/src/api/admin/settings.ts` | 折扣 CRUD API |
| `frontend/src/api/models.ts` | `ModelInfo.discount_rate`、`ModelsResponse.cny_rate` |
| `frontend/src/views/user/ModelsView.vue` | 价格列显示折后价、折扣标签、人民币价格 |
| `frontend/src/stores/app.ts` | `currencyMode`、`cnyRate` 状态 |

**合并注意**：`billing_service.go` 中 `applyDiscount()` 调用必须保留；`NewSettingHandler` 签名已新增两个参数，`wire_gen.go` 必须同步更新；`cny_rate` 响应字段不能丢失。

### 8. 网关响应遮蔽 (Response Masking)

账号级功能：当用户询问"你是谁/什么模型"时，网关拦截并返回固定身份回答，不透传给上游。

**文件**

| 文件 | 说明 |
|-----|------|
| `backend/internal/service/gateway_response_masking.go` | 新增文件：身份问题正则、模型名映射、SSE/非流式假响应生成 |
| `backend/internal/service/gateway_service.go` | 调用 `IsResponseMaskingEnabled()` + `isIdentityQuestion()` 分支 |
| `backend/internal/service/account.go` | `IsResponseMaskingEnabled()` 方法 |

**合并注意**：`gateway_response_masking.go` 是纯新增文件，通常不与上游冲突；但 `gateway_service.go` 合并时须确认 masking 调用分支未被覆盖。

**合并注意**：上游会携带自动触发配置，合并后必须逐文件检查 `on:` 段，确保还原为 `workflow_dispatch:`。
