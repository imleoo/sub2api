```go
func (s *adminServiceImpl) GetUserUsageStats(ctx context.Context, userID int64, days int) (any, error) {
    // 复用 dashboardService 的批量查询方法
    now := timezone.Now()
    endTime := timezone.StartOfDay(now.AddDate(0, 0, 1))
    startTime := timezone.StartOfDay(now.AddDate(0, 0, -days+1))

    stats, err := s.dashboardService.GetBatchUserUsageStats(ctx, []int64{userID}, startTime, endTime)
    if err != nil {
        return nil, err
    }

    if stat, ok := stats[userID]; ok {
        return map[string]any{
            "period":             fmt.Sprintf("last_%d_days", days),
            "total_requests":    stat.TotalRequests,
            "total_cost":        stat.TotalCost,
            "total_tokens":      stat.TotalTokens,
            "avg_duration_ms":   stat.AvgDurationMs,
        }, nil
    }

    return map[string]any{
        "period":          fmt.Sprintf("last_%d_days", days),
        "total_requests":   0,
        "total_cost":      0.0,
        "total_tokens":    0,
        "avg_duration_ms": 0,
    }, nil
}
```

**改动说明**: 复用 `dashboardService.GetBatchUserUsageStats`，无需新增 repo 方法。

```go
func (h *UserHandler) GetUserUsage(c *gin.Context) {
    userID, err := strconv.ParseInt(c.Param("id"), 10, 64)
    if err != nil {
        response.BadRequest(c, "Invalid user ID")
        return
    }

    days := 30
    if daysStr := c.Query("days"); daysStr != "" {
        if d, err := strconv.Atoi(daysStr); err == nil && d > 0 && d <= 90 {
            days = d
        }
    }

    stats, err := h.adminService.GetUserUsageStats(c.Request.Context(), userID, days)
    if err != nil {
        response.ErrorFrom(c, err)
        return
    }

    response.Success(c, stats)
}
```

**改动说明**: 增加 `days` 参数支持，与 `AccountHandler.GetStats` 接口对齐。

## ⚠️ 需求 4: 对用户提示词进行词云分析

### 当前系统能力

**数据存储现状**:
- ❌ `usage_logs` 表**不存储**用户提示词内容
- ❌ 数据库中**没有** prompt/messages/content 字段
- ✅ 仅记录元数据（token数、模型、成本等）

**为什么不存储提示词**:
1. **隐私合规**: 用户提示词可能包含敏感信息
2. **存储成本**: 提示词内容体积大，长期存储成本高
3. **性能考虑**: 不影响核心计费和统计功能

### 核心矛盾

> **如何获取提示词数据，同时保持对上游代码的最小侵入性？**

---

### 插件化实现方案：最小侵入设计

#### 关键发现：现有中间件机制

`OpsErrorLoggerMiddleware` 是最佳参考模式：

```
请求进入 → routes/gateway.go 中间件链 → handlers/gateway_handler.go
  │
  ├─[中间件] apiKeyAuth          ← 现有，认证
  ├─[中间件] opsErrorLogger       ← 现有，在 handler 完成后取 body 做分析
  │            │
  │            └── setOpsRequestContext(c, model, stream, body)
  │                     └─ 将 body 写入 gin.Context: c.Set("ops_request_body", body)
  │            └── handler 完成后: c.Get("ops_request_body") → 做 OPS 日志分析
  │
  └─[Handler] h.Gateway.Messages ← 现有，完全不动
```

**`setOpsRequestContext` 已在 handler 中被调用**（10+ 处），**Body 已写入 context**。

#### 关键词提取策略

**不在数据库中存储原始提示词**，仅提取关键词统计：

```go
type KeywordExtractor struct {
    stopWords   map[string]bool
    maxKeywords int
    samplingRate float64  // 建议 1-10%
}

func (e *KeywordExtractor) ExtractKeywords(prompt []byte) []string {
    // 1. JSON 解析提取 messages 数组中的 text 内容
    // 2. 分词（简单空格/标点分词，或中文 jieba）
    // 3. 过滤停用词
    // 4. 过滤短词（<2字符）
    // 5. 返回高频关键词

```

**优势**：
- 🚫 不存储原始提示词（无隐私风险）
- 🚫 存储体积极小（仅关键词+计数）
- 🚫 性能影响最小（异步处理，不阻塞响应）
- ✅ 可生成词云

#### ⚠️ 技术债评估

**1. 中文分词依赖**

| 方案 | 支持语言 | 依赖复杂度 | 推荐度 |
|------|---------|-----------|--------|
| 简单空格/标点分词 | 英文 | 无额外依赖 | ⭐⭐⭐ |
| 正则分词 + 停用词 | 中英文 | 无额外依赖 | ⭐⭐⭐⭐ |
| `gojieba` 库 | 中文 | 增加编译依赖 + CGO | ⭐⭐ |

**建议**: 初期采用**正则分词方案**，后续按需升级。

**2. 性能开销评估**

| 影响点 | 开销 | 缓解措施 |
|--------|------|---------|
| JSON 解析 | 每请求 ~1-5ms | 异步处理 |
| 分词计算 | 每提示词 ~0.1-1ms | 采样率控制 |
| 内存占用 | 队列缓冲 ~10MB | 限制队列大小 |

**建议配置**:
```go
samplingRate: config.GetFloat("prompt_analytics.sampling_rate", 0.05) // 5% 采样
maxQueueSize: 1000
batchWindow:  200 * time.Millisecond
```

**3. 关键词表清理策略**

关键词表会随时间持续增长，需设计 TTL 清理：

```go
// config.go
type Config struct {
    RetentionDays int `yaml:"retention_days"` // 默认 90 天
}

// repository.go
func (r *repo) CleanupOldKeywords(ctx context.Context, before time.Time) (int64, error) {
    return r.client.KeywordStats.Delete().
        Where(keywordstats.CreatedAtLT(before)).
        Exec(ctx)
}
```

**定时任务**:
```go
// 每天凌晨 3 点执行清理
go func() {
    ticker := time.NewTicker(24 * time.Hour)
    for range ticker.C {
        cutoff := time.Now().AddDate(0, 0, -config.RetentionDays)
        repo.CleanupOldKeywords(ctx, cutoff)
    }
}()
```
