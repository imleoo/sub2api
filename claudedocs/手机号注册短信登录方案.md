# 手机号注册 + 火山引擎短信登录方案

> 分支：`zhiguofan`  
> 状态：待实现  
> 日期：2026-06-01

---

## 一、需求概述

1. 管理后台新增功能开关：**手机号注册模式**，与邮箱注册**互斥**（二选一）。
2. 手机号注册模式下，用户通过「手机号 + 短信验证码」完成注册。
3. 手机号注册模式下，支持「手机号 + 短信验证码」直接登录（注册即登录，首次自动建账）。
4. 短信服务接入**火山引擎 SMS**（接口文档：<https://www.volcengine.com/docs/6361/1109261>）。

---

## 二、架构总览

```
注册模式互斥逻辑：
  phone_register_enabled = true  ←→  email_verify_enabled 强制置 false
  phone_register_enabled = false →   保持现有邮箱注册逻辑不变

新增 API 端点（公开，带限流）：
  POST /api/v1/auth/send-sms-code    发送短信验证码
  POST /api/v1/auth/phone-register   手机号注册
  POST /api/v1/auth/phone-login      手机号+验证码直接登录
```

现有邮箱/密码登录路由（`/api/v1/auth/login`）**始终保留**，以便 admin 账号不受影响。

### 3.3 火山引擎 SMS 客户端 — `internal/pkg/sms/volcengine.go`（新建）

**不引入新的第三方 SDK**，用标准 `net/http` + HMAC-SHA256 实现火山引擎 OpenAPI 签名（与 AWS Signature V4 兼容）。

```go
package sms

type VolcengineConfig struct {
    AccessKeyID     string
    AccessKeySecret string
    AccountID       string
    Sign            string
    TemplateID      string
}

type VolcengineClient struct {
    cfg        VolcengineConfig
    httpClient *http.Client
}

func NewVolcengineClient(cfg VolcengineConfig) *VolcengineClient

// SendCode 向单个手机号发送验证码短信
// phone 格式：+8613812345678
// code：6位数字验证码
func (c *VolcengineClient) SendCode(ctx context.Context, phone, code string) error
```

**关键实现要点**

- API 端点：`https://sms.volcengineapi.com/` Action=`SendSms` Version=`2020-01-01`
- 签名算法：HMAC-SHA256，Header 中携带 `Authorization: HMAC-SHA256 Credential=...`
- 模板参数：`{"code": "123456"}`，具体参数名以实际模板配置为准

Redis key 前缀 `sms_verify_code:`，与邮箱 key `verify_code:` 完全隔离。

实现接口：

```go
// internal/service/sms_service.go 中定义
type SmsCache interface {
    GetSmsVerifyCode(ctx context.Context, phone string) (*service.VerificationCodeData, error)
    SetSmsVerifyCode(ctx context.Context, phone string, data *service.VerificationCodeData, ttl time.Duration) error
    DeleteSmsVerifyCode(ctx context.Context, phone string) error
}
```

复用 `service.VerificationCodeData` 结构体，无需新定义。

### 3.5 SMS Service — `internal/service/sms_service.go`（新建）

```go
type SmsService struct {
    cache       SmsCache
    settingRepo SettingRepository
}

func NewSmsService(cache SmsCache, settingRepo SettingRepository) *SmsService

// SendVerifyCode 生成验证码并通过火山引擎发送
// 冷却：60s；最大尝试：5次；有效期：15min（与邮件验证码策略一致）
func (s *SmsService) SendVerifyCode(ctx context.Context, phone string) (*SendSmsCodeResult, error)

// VerifyAndConsume 验证验证码并消费（防重放）
func (s *SmsService) VerifyAndConsume(ctx context.Context, phone, code string) error
```

**手机号归一化**：内部统一将 `13812345678` → `+8613812345678`，国际号码直接保留。

### 3.6 AuthService 新增方法 — `internal/service/auth_service.go`

```go
// RegisterWithPhone 手机号注册（内部调用 VerifyAndConsume 后创建用户）
func (s *AuthService) RegisterWithPhone(
    ctx context.Context,
    phone, code, username, promoCode, invitationCode, affiliateCode string,
) (*User, error)

// LoginWithPhone 手机号验证码登录，首次自动注册
func (s *AuthService) LoginWithPhone(
    ctx context.Context,
    phone, code string,
) (*User, error)
```

`RegisterWithPhone` 逻辑：
1. 调用 `smsService.VerifyAndConsume(ctx, phone, code)`
2. 检查 phone 唯一性
3. 创建 User（`auth_source = "phone"`, `email = NULL`）
4. 执行 promo/invitation/affiliate 逻辑（复用 `RegisterWithVerification` 中的相关段落）

`LoginWithPhone` 逻辑：
1. `smsService.VerifyAndConsume(ctx, phone, code)`
2. 按 phone 查找用户
3. 若不存在 → 调用 `RegisterWithPhone`（用户名自动生成为 `user_手机后四位`）
4. 若存在且 inactive → 返回 `ErrUserNotActive`
5. 返回 User

## 五、关键设计决策

| 问题 | 决策 |
|------|------|
| 互斥强制位置 | 后端 `SaveSettings` 强制写入（防绕过），前端 Toggle 联动提示 |
| email 字段 | 手机注册用户 `email = NULL`，不影响现有唯一索引（需确认 ent schema unique 约束） |
| Admin 账号兼容 | `/auth/login`（邮箱/密码）路由始终保留，不受开关影响 |
| 火山引擎 SDK | 纯 HTTP + HMAC-SHA256，不引入第三方依赖 |
| 手机号格式 | 存储 `+8613812345678`；接收 `13812345678` 时自动补 `+86` |
| 验证码 Redis key | `sms_verify_code:+8613812345678`，与邮件 `verify_code:` 前缀隔离 |
| 登录首次自动注册 | `LoginWithPhone` 遇到新手机号自动创建账号（用户名 = `user_{后四位}`），保持与 OAuth 登录行为一致 |
| test stub 更新 | 新方法加入 AuthService 接口后，需 `grep -r "type.*Stub.*struct" internal/` 全量补全 |

## 七、测试要点

### 后端单元测试

- `SmsService.SendVerifyCode`：冷却/频率限制/TTL

- `AuthService.LoginWithPhone`：新号码自动注册、已注册号码登录、inactive 用户
- `SettingService.SaveSettings`：互斥逻辑（启用 phone 时 email_verify 置 false）

- `LoginView`：phone 模式表单渲染、切换密码登录入口
